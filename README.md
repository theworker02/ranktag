# ranktag

Rank timestamps and tag durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/ranktag/

## Install / run

```bash
git clone https://github.com/theworker02/ranktag.git
cd ranktag
node src/cli.js
node --test
```
